# 二维周期性山丘预注册：粗网格 RANS + 独立 LES/DNS 参考

**定位：** 一维槽道 Demo 之后的二维方法验证，不是完整 CFD 验证，也不是把合成真值换一个名字继续跑。  
**目标：** 在**粗网格 RANS** 基线和一个**独立的高保真 LES/DNS 参考**之间，检验结构化闭合残差修正能否稳定改善未见剖面，并且用独立的壁面剪应力和整体力平衡来判定，而不是复用一维的构造恒等式。

本文件在二维训练开始前冻结。任何阈值、数据划分或参考数据来源的改动都必须先写入新的 ADR，再重跑实验。

## 1. 与 ADR-0002 / ADR-0003 的一致性

ADR-0002 允许进入二维，但要求：

1. 主要假设限定为“结构化残差修正可在 coarse RANS 中保持稳定”，不声称所有物理约束都有独立边际贡献；
2. 二维必须使用更高保真参考或真实 LES/DNS 子集，不能只复用合成真值；
3. 保留 A2/A3 的零结果，优先研究可观测性，而不是继续加网络容量。

ADR-0003 进一步要求：

1. 二维壁面剪应力必须从解出的壁面法向速度梯度和有效黏度计算，再由 `u_tau = sqrt(abs(tau_w))` 反推，不得把 `u_tau` 当自由输入；
2. H3 至少同时检查局部 `tau_w` 相对高保真参考误差、周期/整体动量力平衡残差、固定点收敛和逐种子失败率；
3. 任何预算结论至少覆盖两个嵌套预算和 20 个种子，求解器不收敛是独立失败类别。

## 3. 几何与流动设置

采用 h = 1 的无量纲化：

- 山高：`h = 1`
- 周期长度：`Lx = 9h = 9`
- 通道高度：`Ly = 3.035h = 3.035`
- 山体下边界：`y = b(x)`，`b(x)` 由 `geom.dat` 的分段三次多项式给出；`x/h > 54/28` 后为平板 `b = 0`
- 上壁面：`y = 3.035`，无滑移
- 流向：周期边界
- 壁面：无滑移；二维壁面剪应力从解出的 `du/dn` 与有效黏度计算
- 体积流量：`Q = U_b * (Ly - h) = 2.035`，其中 `U_b = 1` 是按山脊处流通面积定义的体速度

参考 LES 的雷诺数：`Re_h = U_b h / nu = 10595`，因此 `nu = 1 / 10595`。

## 4. 粗网格 RANS 基线

### 4.1 网格

至少两个嵌套粗网格：

| 网格 | nx | ny | 用途 |
|---|---:|---:|---|
| G1 | 48 | 24 | 粗网格基线、快速消融 |
| G2 | 96 | 48 | 主基线、预注册正式结果 |
| G3 | 192 | 96 | 只做网格敏感性检查，不作为训练网格 |

`nx` 为流向单元数，`ny` 为壁法向单元数。G1/G2/G3 必须使用同一套边界条件、闭合模型和收敛容差。G3 只回答“解是否随网格收敛”，不参与残差修正的参数选择。

### 4.2 离散

第一版允许使用一个透明、可复现的教学级求解器：

- 二维不可压缩 RANS，pseudo-time marching；
- staggered MAC 网格，压力 Poisson 方程在 x 方向用 FFT、在 y 方向用三对角求解；
- 对流项至少二阶迎风（SOU）；如果 SOU 在 G1 上不稳定，可以退化为混合一阶/二阶，但必须在报告中记录；
- 扩散项中心差分；
- 山体用 sharp immersed-boundary/stair-step 掩膜处理，不引入山体内部的通量；
- 上壁与平板段用无滑移 ghost；
- 驱动方式：常体力 `f0`，用积分控制器调 `f0` 使 `Q -> 2.035`；控制器只允许调整驱动力，不得接触参考剖面。

这个求解器的定位是“故意粗糙、结构误差可观测的基线”，不是经过验证的 CFD 求解器。它的数值误差与闭合误差必须在报告中分开说明；如果无法分开，不得把全部误差都归因于闭合。

### 4.3 基准闭合

使用带壁面阻尼的 mixing-length 涡黏模型：

```text
nu_t = l(y_w)^2 * |S|
l(y_w) = min(kappa * y_w, l_cap)
y_w = min(y - b(x), Ly - y)
```

固定参数：`kappa = 0.41`，`l_cap = 0.09 * (Ly / 2)`。  
不允许用参考 LES 剖面拟合 `kappa`、`l_cap` 或任何等效系数。

修正模型输出的是**闭合修正量**，例如

```text
nu_t^theta = nu_t^base * exp(delta(x, eta, Re, ...))
```

或等价的加性修正。网络不直接输出速度场；速度场由 RANS 解出。

### 4.4 求解器验收门（训练前）

在进入任何神经网络训练之前，粗网格 RANS 必须通过：

1. **平板极限**：把 `b(x)` 置零后，G1/G2 在层流 `Re = 1` 情形下与解析抛物线的最大相对误差 < 2%；
2. **质量守恒**：每一步投影后的最大散度 < `1e-8 / dt`（归一化后按报告定义）；
3. **周期性**：所有场在 x 方向严格周期，山脊前后无人工阶跃；
4. **分离/再附**：G2 在 `Re_h = 10595` 下必须出现分离泡，且分离/再附位置与参考值的差不超过 ±2h；如果 G2 不出现分离或分离位置超过 x/h = 8，求解器/闭合配置不通过，不得进入训练；
5. **网格敏感性**：G2 与 G3 的 reattachment 位置差 < 1h，主流区速度剖面的相对 L2 差 < 10%；如果 G1 与 G2 差异很大，只允许 G2/G3 作为正式网格，G1 仅用于消融；
6. **力平衡**：G2 的周期/整体动量力平衡残差 < 5%（定义见 6.3）。

任一项不过，二维实验停止在求解器阶段，先修求解器，不得用神经修正“掩盖”离散或边界条件错误。

## 5. 观测点与评估网格

### 5.1 站点划分

把十个参考站分成互不重叠的三组：

| 组 | x/h | 用途 |
|---|---|---|
| 训练站点 | 0.5, 1, 2, 6 | 仅用于构造观测点 |
| 验证站点 | 3, 7 | 训练期监控和早停，不参与最终报告 |
| 测试站点 | 0.05, 4, 5, 8 | 最终评估，训练和验证均不可见 |

站点划分在训练前冻结。若某站点的参考剖面不足以构造所需观测预算，宁可减少预算，也不得把测试站点挪进训练组。

### 5.2 观测预算

在两个嵌套预算上评估：

| 预算 | 总观测点数 | 说明 |
|---|---:|---|
| B1 | 32 | 每站 8 个壁法向点，嵌套自 B2 |
| B2 | 64 | 每站 16 个壁法向点，包含 B1 |

每个预算在训练站点上按壁法向分层采样；保证 B1 ⊂ B2。每个预算跑 20 个随机种子。观测噪声：仅对训练观测加 1% 相对噪声；验证/测试参考保持干净。

### 5.3 评估网格

评估使用：

- 测试站点的全部参考点；
- 训练/验证站点中未被观测点覆盖的剩余点（作为“同站外推”诊断）；
- 壁面剪应力曲线 `tau_w(x/h)`；
- 整体力平衡；
- 分离/再附位置。

评估点与观测点不重叠。最终报告必须同时给出：

- 同站外推误差；
- 跨站误差（测试站点）；
- 壁面剪应力误差；
- 失败率（不收敛的求解器运行数）。

### 5.4 泄漏隔离检查

在训练前运行并保存以下检查：

1. 任何训练输入不得包含 `uu`、`vv`、`uv`、`k` 字段；
2. 任何训练损失不得使用测试站点；
3. 超参数选择只能看验证站点；
4. 壁面剪应力参考不得进入训练损失或输入特征；
5. 最终评估脚本只读冻结的模型和测试文件，不重新训练、不重新选点。

## 6. 评价指标

### 6.1 平均速度

主指标是测试站点上的相对 L2 误差：

```text
E_U = ||U_rans - U_ref||_2 / ||U_ref||_2
```

同时报告：

- 基线 `E_U^base`；
- 数据-only 模型 `E_U^data`；
- 完整模型 `E_U^full`；
- 每个种子、每个预算、每个站点的值。

### 6.2 壁面剪应力

二维 `tau_w` 由解出的壁面法向梯度与有效黏度计算：

```text
tau_w = (nu + nu_t)|_wall * (du/dn)|_wall
u_tau = sqrt(abs(tau_w))
```

参考 `tau_w` 由 LES 近壁速度剖面独立拟合得到，不使用任何构造恒等式。报告每个站点的相对误差：

```text
e_tau(x) = |tau_w^rans(x) - tau_w^ref(x)| / |tau_w^ref(x)|
```

同时报告 `u_tau` 的推断值和参考值；`u_tau` 不是求解器输入。

### 6.3 周期/整体动量力平衡

对周期域，整体流向动量平衡必须闭合：

```text
F_body + F_pressure,hill + F_shear,wall = 0
```

定义归一化残差：

```text
r_balance = |F_body + F_pressure,hill + F_shear,wall| / max(|F_body|, |F_shear,wall|)
```

其中 `F_pressure,hill` 是山体表面的流向压力力，`F_shear,wall` 是全部壁面的剪切力。`r_balance` 必须与局部 `tau_w` 一起报告；两者不能互相替代。

### 6.4 分离/再附与固定点

- `x_sep`、`x_reattach`：壁面剪应力符号变化点的线性插值；
- 固定点残差：`max |F(nu_t) - nu_t|`；
- 迭代次数；
- 逐种子状态：`converged` / `max_iter` / `diverged` 三类，禁止把 `max_iter` 的巨大末次误差当作精度值参与平均。

## 7. 预注册判据

以下阈值在二维训练开始前冻结。全部按“每个预算 × 20 个种子”报告，并给出中位数、四分位数和失败数。

### H1：有可学习、可参数化的残差

- 完整模型在测试站点上的相对 L2 误差相对基线改善至少 **20%**（中位数）；
- 20 个种子的 bootstrap 95% 置信区间下界 > 0；
- 失败率不高于基线的失败率 + 1 个种子。

### H2：物理约束带来外推优势

- 完整模型相对 data-only 模型在测试站点上的相对 L2 误差至少低 **10%**，或失败率显著更低；
- 如果完整模型与 data-only 相当，报告为“物理约束没有显示边际优势”，不得把等价写成通过；
- 各物理轴消融（去结构约束、去 RANS 残差、去平滑）必须逐种子报告；一维 A2/A3 的零结果保留到二维讨论中。

### H3：冻结修正进入求解器

- 20/20 种子固定点收敛；
- 最大固定点残差 < `1e-6`；
- 无发散、无 NaN；
- 完整模型的局部 `tau_w` 相对误差中位数 ≤ **10%**；
- 整体力平衡残差中位数 ≤ **2%**；
- 壁面剪应力改善不能只来自构造恒等式：必须同时看到局部 `tau_w` 和整体力平衡的独立改善。

如果 H1 成立但 H2 不成立，结论限定为“在观测站附近有效，不能证明外推”。  
如果 H3 不成立，停止扩展到更复杂几何，转向弱耦合或混合数值方法。

## 8. 预算与执行

### 8.1 预算

- 观测预算：B1 = 32，B2 = 64；
- 种子：每个网格/预算/臂至少 20 个；
- 臂：`full`、`data_only`、`no_structure`、`no_rans`、`no_smooth`；
- 正式报告只使用 G2；G1 用于快速失败检测，G3 用于网格敏感性；
- 训练超参数在验证站点冻结后，不允许再按测试站点修改。

### 8.2 实施顺序

1. **T10.1 参考数据与几何**：下载、校验、解析 ERCOFTAC case 081；验证十个站点和 `geom.dat` 样条；建立 `wall_normal_coordinate`。
2. **T10.2 粗网格 RANS 求解器**：实现并验证平板极限、周期性和质量守恒；在 G1/G2/G3 上跑基线。
3. **T10.3 可观测量**：实现 `tau_w`、`u_tau`、整体力平衡、分离/再附诊断；在基线解上做独立回归测试。
4. **T10.4 观测设计与泄漏隔离**：冻结站点划分、嵌套预算、噪声和评估脚本。
5. **T10.5 训练**：在同一网络/训练器上接入二维 `PDEProblem`，网络只输出闭合修正。
6. **T10.6 预注册评估**：按第 7 节跑完并保存原始逐种子结果；生成报告和图表。

## 9. 停止条件

- 参考数据无法获取、校验失败或站点缺失：停止；不得用合成真值替代独立参考。
- 平板极限、质量守恒或周期性检查失败：停止在求解器阶段，先修求解器。
- G2 不出现分离或分离/再附超出第 4.4 节门限：停止，先修离散、边界或闭合。
- H1/H2/H3 任一不通过：按负结果报告；不得通过事后改阈值、扩大预算或替换测试站点来挽救结论。
- 如果只有 G1 能跑、G2/G3 失败：不得把 G1 的单次结果升级为二维结论。

## 10. 与一维结果的边界

一维 Demo 的结论只在以下范围内继承：

- 结构化参数化和冻结耦合的稳定性假设，可以带到二维重新检验；
- 一维 `tau_w = u_tau^2` 是构造恒等式，二维完全不复用；
- 一维 A2/A3 的单轴消融零结果必须保留；
- 一维 `Re_tau = 590` 外推是槽道特定设置，二维的“外推”主要指未见站点、未见壁法向区域和不同观测预算，不自动等价为不同雷诺数外推。

二维的最终结论只有在独立 LES 参考、局部壁面剪应力和整体力平衡三者同时站得住时，才能写入正式开题材料。
