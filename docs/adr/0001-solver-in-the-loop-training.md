# 训练内层也跑不动点迭代（solver-in-the-loop）

闭合修正依赖局地剪切 `S = dU/dy`，而 `S` 又由 `νt` 决定 —— 要拿到自洽的 `U` 和 `S`，训练时 `losses()` 内部就得解一次不动点。

决定：**训练内层与耦合实验（E5）用同一个不动点求解器**，不把 `S` 冻结在基准剪切上。代价是每次 loss 求值多约 20 次迭代；1D 上这是 cumsum 级别，可接受。

理由是 H3 要证的是「冻结的修正嵌入求解器后不发散」。如果训练时用的是冻结剪切的近似，E5 测的就是一个从未被训练过的耦合 —— H3 便无法证伪，那它该从论证里删掉，而不是留个自明的结论充数。

## Considered Options

- **冻结剪切**：便宜，但 H3 失效。
- **每次 loss 求值重解**（本决定）：贵，但训练与评估的耦合是同一个东西。
