# 粗网格 RANS + PINN 神经残差修正：最小论证 Demo 方案

**Demo 名称：** 物理约束神经残差修正的一维湍流槽道流验证  
**定位：** 正式开题前的可行性论证，不是完整 CFD 验证  
**目标周期：** 1–2 周  
**核心问题：** 物理约束神经残差修正能否在少量高保真剖面数据下改善粗网格 RANS，并外推到未见雷诺数？

## 1. Demo 要证明什么

不是证明“PINN 能求解湍流”，而是证明以下三个可证伪假设：

### H1：有可学习的残差

粗网格 RANS 与高保真参考解之间存在稳定、可参数化的湍流闭合/动量残差，而不是纯随机误差。

### H2：物理约束比纯数据拟合更稳

加入 RANS 方程残差、壁面约束和正性约束后，模型在训练雷诺数之外仍能改善预测。

### H3：离线修正能进入求解器而不发散

冻结训练好的修正模型，嵌入一个简单 RANS 迭代后，速度剖面和壁面剪应力改善，迭代保持稳定。

如果 H1/H2/H3 中任何一个明显失败，就不能直接把该方法推到二维分离流或三维工程算例。

## 2. 为什么先做一维槽道流

一维充分发展槽道流是最合适的论证载体：

- 物理清晰，没有复杂几何和分离结构；
- 有成熟的壁面律和经典标度；
- 计算成本低，几秒钟可以完成一次求解；
- 可以直接观察闭合误差和离散误差；
- 适合做消融、外推和耦合稳定性实验；
- 如果在一维都不成立，扩展到周期性山丘或后台阶没有意义。

**Demo 结论的边界：** 它只能说明方法在平衡湍流和非平衡误差控制上是否有潜力，不能替代真实 DNS/LES 验证。

## 3. 物理和数学设置

### 3.1 无量纲槽道流

采用半槽道 \(y\in[0,h]\)，壁面在 \(y=0\)。充分发展槽道流的平均动量方程为

\[
\frac{d}{dy}\left[(\nu+\nu_t)\frac{dU}{dy}\right]
=\frac{1}{\rho}\frac{d\bar p}{dx}
=-\frac{u_\tau^2}{h}.
\]

积分得到总剪应力关系：

\[
(\nu+\nu_t)\frac{dU}{dy}
=u_\tau^2\left(1-\frac{y}{h}\right).
\]

无量纲化后使用

\[
y^+=\frac{y u_\tau}{\nu},\qquad
U^+=\frac{U}{u_\tau}.
\]

### 3.2 基准模型

使用混合长度型涡黏模型：

\[
\nu_t^{base}
=\kappa y\left(1-\frac{y}{h}\right)u_\tau,
\]

可附加近壁阻尼函数。它故意保留一个可观测的闭合误差，用于验证残差修正能力。

### 3.3 目标模型

构造一个“已知真值”的受控实验：

\[
\nu_t^{true}
=\nu_t^{base}\left[1+\Delta f(y^+,Re_\tau)\right],
\]

其中 \(\Delta f\) 可采用：

- 随 \(y^+\) 变化的壁面阻尼偏差；
- 随雷诺数变化的对数层斜率偏差；
- 局部代理误差；
- 直接使用真实 DNS 的 \(U^+\) 或 \(\nu_t\) 数据，作为第二阶段。

第一版 Demo 使用合成真值，目的是验证算法能否恢复已知修正；第二版再替换为公开 DNS。

## 4. 神经网络模型

### 4.1 输入

建议输入：

\[
x=\left[y/h,\ y^+,\ Re_\tau,\ S^+,\ \nu_t^{base}/\nu,\ \mathrm{boundary\ feature}\right].
\]

第一版至少保留：

- \(y/h\)；
- \(y^+\)；
- \(Re_\tau\)；
- 基准涡黏或局部剪切信息。

### 4.2 输出

两种可选输出：

**方案 A：涡黏残差**

\[
\nu_t^\theta=\nu_t^{base}+\Delta\nu_t^\theta.
\]

**方案 B：应力残差**

\[
\tau^\theta=\tau^{base}+\Delta\tau^\theta,
\quad
\tau=(\nu+\nu_t)\frac{dU}{dy}.
\]

推荐先做方案 A，物理含义直观，便于观察正性和壁面渐近。

### 4.3 网络结构

第一版不需要大模型：

- MLP：3–4 层；
- 每层 32–64 个神经元；
- tanh 或 SiLU；
- 输入做标准化；
- 输出做尺度约束；
- 固定随机种子，至少重复 3 次。

网络训练的是“修正量”，不是直接拟合完整流场。

## 5. 损失函数

总损失：

\[
\mathcal L=
\lambda_d\mathcal L_{data}
+\lambda_r\mathcal L_{RANS}
+\lambda_b\mathcal L_{BC}
+\lambda_p\mathcal L_{physics}
+\lambda_g\mathcal L_{reg}.
\]

### 5.1 数据损失

从高保真参考中取 8–16 个稀疏点：

\[
\mathcal L_{data}
=\frac{1}{N_d}\sum_i
\left(\hat U^+_i-U^{+}_{ref,i}\right)^2.
\]

### 5.2 RANS 残差

\[
\mathcal L_{RANS}
=\frac{1}{N_c}\sum_j
\left[
\frac{d}{dy}\left((\nu+\nu_t^\theta)\frac{d\hat U}{dy}\right)
+\frac{u_\tau^2}{h}
\right]^2.
\]

### 5.3 壁面和积分约束

- \(U(0)=0\)；
- \(\nu_t(0)=0\)；
- 壁面剪应力或总剪应力匹配；
- 槽道中心线对称条件；
- 质量流量可选约束。

### 5.4 物理约束

- \(\nu_t^\theta\ge0\)；
- 近壁渐近 \(\nu_t\sim y^3\) 或采用阻尼函数；
- 修正项有界且平滑；
- 不出现负耗散；
- 在 \(y/h=0,1\) 处满足对称/边界行为。

## 6. 实验设计

### 6.1 数据划分

建议：

| 用途 | 雷诺数 | 说明 |
|---|---|---|
| 训练 | \(Re_\tau=180、395\) | 两个不同雷诺数 |
| 验证 | 395 的留出剖面点 | 超参数选择 |
| 测试 | \(Re_\tau=590\) | 未见雷诺数外推 |
| 可选测试 | 一个压力梯度槽道 | 非平衡性初步测试 |

每个雷诺数只给 8–16 个高保真观测点，其余点只参与 RANS 残差约束。

### 6.2 对比方法

必须至少包含：

1. 基准混合长度/标准 RANS；
2. 无物理约束的纯数据 MLP；
3. 物理约束神经残差修正；
4. 只使用 RANS 残差、不使用高保真数据；
5. 理想真值修正上界。

如果时间允许，再加入：

6. 标准 \(k\)-\(\varepsilon\) 或 \(k\)-\(\omega\) 模型；
7. 固定常数涡黏校准；
8. 不同训练数据量的曲线。

### 6.3 实验矩阵

| 实验 | 训练 Re | 测试 Re | 观测点数 | 目的 |
|---|---|---:|---:|---|
| E1 | 180 | 180 | 16 | 基本拟合能力 |
| E2 | 180 + 395 | 395 | 8/12/16 | 数据量和泛化 |
| E3 | 180 + 395 | 590 | 12 | 雷诺数外推 |
| E4 | 180 + 395 | 590 | 12 | 去掉 PDE/物理约束消融 |
| E5 | 最优模型 | 590 | 12 | 冻结嵌入迭代求解 |
| E6 | 最优模型 | 压力梯度算例 | 12 | 初步非平衡测试 |

## 7. A posteriori 耦合 Demo

这是整个论证 Demo 最关键的一步。

### 第一步：离线训练

用已知高保真剖面训练神经修正模型。

### 第二步：冻结模型

不再更新网络权重，只把模型作为局部修正查询函数。

### 第三步：嵌入 RANS 迭代

采用欠松弛更新：

\[
\nu_t^{n+1}
=(1-\alpha)\nu_t^n
+\alpha\left(\nu_t^{base}+\Delta\nu_t^\theta\right).
\]

其中 \(\alpha\in(0,1]\)。先使用较小 \(\alpha\)，观察残差和剖面是否稳定。

### 第四步：比较

- 迭代次数；
- 残差是否振荡；
- 最终速度剖面误差；
- 壁面剪应力；
- 对训练集之外雷诺数的稳定性。

## 8. 评价指标

### 精度

- \(U^+\) 的 \(L_2\)、\(L_\infty\) 误差；
- 壁面剪应力误差；
- 摩擦速度误差；
- 对数律斜率 \(\kappa\) 和截距 \(B\)；
- 涡黏剖面误差。

### 物理性

- RANS 方程残差；
- 总剪应力误差；
- \(\nu_t\ge0\) 违规率；
- 壁面渐近违规；
- 质量流量或动量守恒误差。

### 稳定性

- 迭代是否收敛；
- 需要的迭代次数；
- 修正幅值是否爆炸；
- 不同随机种子的方差。

### 效率

- 离线训练时间；
- 单次查询时间；
- 嵌入求解器后的额外开销。

## 9. 建议的成功判据

以下是论证 Demo 的建议阈值，不是必然结果：

| 判据 | 建议目标 |
|---|---|
| 训练雷诺数内 \(U^+\) 误差 | 相比基准降低 50% 以上 |
| 未见 \(Re_\tau=590\) 误差 | 相比基准降低 30% 以上 |
| 壁面剪应力误差 | 低于 5%–10% |
| PDE 残差 | 不高于基准 |
| 物理约束违规 | 接近零 |
| 耦合迭代 | 不发散，迭代次数不显著增加 |
| 消融实验 | 去掉物理约束后外推明显变差 |

如果 E3 不成立，但 E2 成立，说明方法更像插值，不足以支撑“外推能力”这一论点。  
如果 E5 不成立，说明离线模型不能进入求解器，必须转向更稳定的弱耦合或混合数值方法。

## 12. 风险和停止条件

| 风险 | 观察 | 处理 |
|---|---|---|
| 合成真值过于理想 | 网络轻松拟合但无实际意义 | 加入噪声、缺失点、雷诺数偏移 |
| 纯数据模型也很强 | PINN 物理约束优势不明显 | 增加外推测试和非平衡压力梯度 |
| 物理约束抑制拟合 | 训练误差居高不下 | 调整权重，使用自适应/课程训练 |
| 耦合发散 | 残差振荡 | 降低修正幅、欠松弛、改弱耦合 |
| 目标残差不可辨识 | 多个场满足同一方程 | 增加壁面剪应力、流量或应力观测 |

**停止条件：** 如果一维槽道流在未见雷诺数上无法稳定改善，先不要扩展到二维分离流；应优先研究误差分解、物理约束和目标可观测量，而不是盲目增加网络规模。

## 13. 与正式课题的衔接

Demo 通过后，按以下顺序扩展：

```text
一维槽道流
→ 二维周期性山丘或后台阶
→ 粗网格 RANS 求解器弱耦合
→ 不同雷诺数和压力梯度外推
→ 三维简化工程算例
```

一维 Demo 的作用不是直接产出最终论文结论，而是回答一个非常具体的问题：

> 物理约束神经残差修正是否值得投入后续二维/三维 CFD 研究？

只有 Demo 在 H1/H2/H3 上给出明确证据，题目才应进入正式开题。
